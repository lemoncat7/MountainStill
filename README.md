# 山隐 · Mountain Still

新玩家全程修订 v1.3.8 · 从入山到归山 · 第一卷「山河归心」。留一小片山色在屏幕下沿，静坐、采药、炼丹，与灵狐慢慢走过五大境界。没有登录、联网、内购、广告或失败惩罚。

## 先玩起来

当前 v1.3.8 把入山、挂机、学习、通脉、突破、打斗、搜寻和制作接成可续玩的第一卷。已接受的原画、比例、拳头握持、衣装模板和注册式攻击模组保持不变。请用 Godot 4.6.3 导入 `project.godot` 并运行。本次第一版测试发布以 v1.3.8 为基线，提供 Windows x86_64 与 macOS Universal 压缩包；具体导出验证结果及平台限制见 [第一版测试说明](FIRST_TEST_README.md)。历史程序包不包含当前全部更新。

- Windows（Intel / AMD 64 位）：解压 Windows ZIP，运行 `MountainStill.exe`。
- macOS（Apple Silicon + Intel）：解压 macOS Universal ZIP，打开其中的 `.app`。
- Linux：本次未附独立包，可用 Godot 4.6.3 导入源码运行。

Windows 构建没有发布者签名。macOS 使用 Godot 的 ad-hoc 签名，没有 Apple Developer ID 和公证；系统可能阻止打开。请审阅来源，不要关闭系统整体安全保护。也可使用 Godot 4.6.3 导入源码运行。Windows/macOS 的成功导出不等于目标系统实机验证，历史程序包的验证范围见 [v1.3.1 动作修订记录](docs/COMBAT-v1.3.1-QA.md)。

## 本轮：从新入山到六印归心

从新存档开始，原有系统现在由同一条实际进度指引串起：行装、采药、研习、通脉、突破、手选山路、搜寻、百工、章间养成与归山尾声。指引在原宣纸册页内，可略过、重看；场景不换位置，也没有新增仪表盘或弹窗教学。

- 新档默认积累灵气、亲手突破，每次展示消耗、下一境与解锁。想安心挂机时自行开启随缘；旧档保留原开关。
- 第一轮云岚第二重调整为6灵草、2晨露、9秒研习，从真实初始资源采药24秒就够。后续重数和其它功法费用不变。
- 当前建议从真实保存状态推导，知道未搜遗物、未完行程、已学未装功法、可制作物、下一章境界与终章；浏览和略过不会发奖。
- 普通材料即可完成先织衣、再制扇并+1的路径。随机装备、木箱与稀有玉不作通关门槛。六章依然每次手选，离线不会打斗。

完整玩家路线与资源用途见 [从入山到归山](docs/PLAYER_JOURNEY-v1.3.8.md)。此前源码开发阶段的验证与原生录像范围见 [v1.3.8验证记录](docs/PLAYER_JOURNEY-v1.3.8-QA.md)。 旧版 26 分 04.367 秒的同一新档原生 UI 自动化影片分为 11 段，顺序与关键位置见 [连续影片索引](docs/PLAYER_JOURNEY-v1.3.8-VIDEO-INDEX.md)。这些旧录像与续玩证据不在本次公开源码包中；已知单次扇光绘制错误与节奏诊断边界均保留在核验记录。

## 保留的原画握持、速度与衣装

- 出手速度现在读取实际「速度」属性，基准为100。既有经脉/功法的加速转换成有效速度，角色和守灵使用同一规则。动作前摇、挥出、接触段、回收和出手间隔随速度变化；技能冷却、受击顿帧、控制及状态持续时间仍按真实时间。当前有效速度范围65～160，重招和轻招保留各自基础节奏。

- 剑、扇、空手各自提供防御关节轨迹。剑身迎向来袭，膝髋承重、后脚接地，受力后保持短暂架势，再连续接回攻击；物理格挡没有通用护盾替身。
- 握持使用未改动的原画拳头，保持原尺寸和手腕动画。剑柄与扇轴回到原有拳头关节；原手臂网格仅拆分绘制顺序，兵器在拳头之后，剑柄尾段仍在持械前臂之后遮挡。
- 现有14张角色和装备切片迁移到固定画布与接合点。肩、袖口、腰、膝、裤脚、鞋口和手腕采用同一模板，旧素材差异只在一次性导入时处理。新装备从空白模板作画，无需增加逐件运行时偏移。
- 人与青苔兽、灵鹤的受击按真实接触部位分配局部压缩、头颈滞后与回稳；轻击、重击和格挡使用不同承压与局部顿帧。未命中和闪避不会额外造伤害或伪造命中反馈。动作表现与伤害结算保持隔离。
- 头部0.86、躯干1.30和短颈参数保留；行囊里人物根节点固定，兵器仍独立悬浮。

## 保留的搜寻与百工

- 守灵倒地后保留身体，停止攻击；角色走近、屈膝俯身搜寻两秒，之后才将材料与宝物收入行囊。收获卡出现后身体再慢慢淡去。没有血腥表现。
- 尸体中的掉落在倒地时固定，搜寻后原子结算一次；暂停、归山和存读档保留未收取物与搜索进度。读档仍在山居，需要亲手点继续。离线不替你杀敌、搜寻或收入新战利品。
- 六族各有材料，另有通用灵息碎屑。现有七张百工配方：凝炼灵息、炼化山材、铸造青锋剑、织造竹影短衫，以及三张随章节领悟的发簪、流云扇和月白云衫配方。灵髓玉为独立 1% 的稀有材料，无保底；原木箱 12%、装备 3% 独立概率保持。
- 打开「行装 → 行囊 → 百工」查看所需、已有、成物属性，再合成或制作。制成装备是实际拥有的物品，要亲手穿戴；同一部位的旧装备保留。
- 衣冠页「淬炼需… ↔ 切换」可在草露与淬炼石之间选择。两条路径均提升原物 +0～5，必定成功。悬停淬炼按钮可查看材料与攻击/防御前后变化。
- 普通格挡用兵器、身体承重和局部卸力表现，实际反击命中显示「反击」。只有主动护元诀产生透明微光防护场，受击亮起、护值耗尽时散成微光；不把普通格挡画成防护罩。

这些搜寻与百工内容在 v1.3.4 引入，主观动作读感仍需用户确认。该版曾保留五项旧战斗时长失败，随后 v1.3.7 调整中段鹤王解决；v1.3.8 当前独立节奏诊断另有两项 6.82 秒短于 7 秒下限的记录，见本版验证文件。历史详情见 [v1.3.4 搜寻与百工记录](docs/LOOTING_CRAFTING-v1.3.4-QA.md)。

## 第一段山居

1. 点击石台，翻开「修行札记」，查看当前境界、入山任务和物华收藏。
2. 点击人物打开「行装谱」。启封随身木箱，选择物品再穿上；不会自动替换衣冠。
3. 新档会静坐积累灵气，突破先由你亲点。需要挂机时在札记开启「随缘」，它才会自动静坐、凑齐灵草并突破；手选活动会关闭随缘。
4. 点击药圃采药，点击丹炉炼丹。第一炉聚气丹需要 3 灵草、1 灵露，基础耗时 20 秒。
5. 点击小灵狐，在寻缘页派它去青竹小径。回山时自动收入资源与见闻；每三次游历带回一只未开启木箱。
6. 完成任务后在札记领取赠礼。沿途解锁功法、丹方和更远的山路，最终抵达归真。

详见 [中文快速入门与内容范围](docs/CAMPAIGN_USER_GUIDE.md)。

## 有限单机第一卷的内容范围

- 炼气、筑基、金丹、元婴、化神五大境界，各有初/中/后期，另有归真终章，共十六个阶段、十五次突破。无装备、丹药、任务或游历帮助的自动修行基准为 8 小时 32 分 52 秒，主动培养会缩短时间。
- 十门可搭配的功法，以心法、武技、术法、护体、身法、炼体、辅助功能等交叠标签查阅。通习容量、同时研习数和心法／武式／主动／辅修栏各有独立限制；功法各有三至七重的上限，研习支付草露后须等真实计时完成，收起功法仍保留已学重数。
- 十种形制、四档品阶的真实装备物品；头饰、上衣、下装、鞋履、兵器五部位独立穿脱，外观即时变化。每件可温养至 +5（衣冠页按钮为「淬炼」），必定成功。无装备时为赤膊白短裤的成年 Q 版修士，短裤始终保留。
- 三种丹方：聚气丹增加修为；回春丹加快采集；澄心丹加快吐纳。温养增益按游戏模拟时间消耗，暂停时不消耗。
- 灵狐伙伴、青竹小径/听泉溪谷/眠云山巅三条路线，六件游历纪念物、亲密成长、十二段递进任务和完成纪念。
- 手动选择六章山路：青竹关、听泉桥、眠云坡、照炉遗墟、镜月泽、归真天门。前章通关与境界达到要求后，点「整装出发」由传送阵入关；角色原地侧身步行、山路向左滚动，遇敌停步交锋，途经机缘，击退镇关首领后传送归山。闲置、离线、读档均不自动出发。收集和主线都不要求战斗。灵狐连续游历仍是独立的可选功能。
- 每次击退固定独立掉落判定，搜寻完成才收入木箱 12%、装备 3%，可以同时获得，也可能都没有；直接掉落珍品概率 0.30%、仙品 0.06%。没有每三胜保底宝箱。途中首领前的石龛有 18% 概率留下一段机缘；停步等待点击选择，没有倒计时。
- 二十二个经脉穴位：保留原有六穴主脉，另有四条各四穴的分支。按前置穴位、境界与草露灵气成本温养，可搭配劲锋、镇岳、游风与归藏四条支脉，培养破势连锋、守中反击、闪身追击或山居养息；经脉不反过来锁住突破。

现有系统覆盖内容有限、可从新存档走到结局的单机第一卷，动作表现仍在逐段打磨。六章各有独立山景、守灵与首领，十八场交锋后六印归一，再回山写下「山河归心」尾声。它不包含多人、云账号、商城、无限地图或大型商业作品规模的逐帧动作库。

章节首通固定赠予真实装备与成长资源，不消耗随机掉落机会。赠礼需要亲手穿戴，突破仍按公开消耗支付；普通掉落保持木箱 12%、装备 3% 的独立概率。固定成长让主动游玩不必等待数小时挂机才能推进章节，安静修行的原有速率保持不变。战败或主动归山保留已击退路段，不扣行装与修为；亲点继续时恢复气血，但不会免费补满本程真气或清空技能冷却。六章完成会解开山路故事，达到归真后可亲手完成归山尾声，之后仍能自由收藏和重游。

本次修正移除普通格挡的弧形护罩，以及剑普攻的宽面拖影。平斩、直刺、挑锋保留真实兵器和握持点，仅留不超过 14 像素的细短剑尖残迹；格挡由横持剑、屈肘、沉肩与膝部承重表现，局部火花只来自真实接触。剑绘在近手前景层，避免被敌人遮住；只有「护元诀」保留透明微光的真正防护场。

行装谱现在显示平常闪避率、出招时闪避率，以及基础、身法、装备、经脉的分项。落英装在已通习的武式或主动栏时，身法防御对剑、扇与空手均有效；扇招仍只在持扇时生效。素布履与踏云靴分别提供 2、4 个百分点，每次淬炼再加 0.2。闪避成功真实后撤侧身、伤害为 0；格挡仍按守势减伤。所有来源只汇总为一次防御判定，不会重复掷骰或把普通落空计成闪避。详细概率与验证范围见 [剑势、格挡与闪避修正](docs/GUARD_EVASION_REVISION.md)。

已接受的侧身模板将头部与头饰缩至 86%，胸背、手臂和腿部分别增加厚度，并缩短可见颈段，使头部自然落在肩领上方。各衣冠分层随对应部位调整，脚底、骨长、握持与兵器触达保持一致。行囊特写将剑／扇独立悬浮在人物旁边，保留清楚间隔；换装即时更新，卸下后消失。正面脸型与原画、场景中的真实握持不变。详见[侧身比例与行囊展示验证](docs/SIDE_PROPORTION_INVENTORY_REVISION.md)。

真实侧身分层角色使用定长关节、按实际行程推进的步态和着地停留；衣物五部位保持独立，出招握持点随手腕运动。山路、路旁物与步态共用连续速度，遇敌前减速收步，交锋后再起步。每只怪物的各姿态按头部与落地锚点校准。苔兽与灵鹤使用独立绘制的进攻关键姿态；其它四族沿用既有姿态，尚未完成同等程度的动作润色。双方行动独立推进，可在对方收势时追击、打断失衡中的招式，闪避与格挡后的反击必须由实际防御结果触发。

免费普攻随真实兵器变化：剑有斩、刺、挑，扇有横拂、点打、回拂，空手用拳掌。兵器自带技与装入主动栏的功法分别耗用「战斗真气」，按各自技能 ID 记录冷却；真气不足时仍可普攻。云岚三叠、落英回锋、照炉炎息、霜缚缓速、鸣雷破势、护元吸伤与回春治疗各有用途，止水与归息则在心法栏被动生效。武式与主动栏独立，选择剑诀不会凭空装备剑；施法时已有兵器收在背后。伤害只在接触时结算，闪避为零伤害，格挡实际减伤。轻击、重击、格挡、破势各有局部停顿、受击姿态、材质音色和接触碎屑；界面与山景不随打击抖动。苔兽、灵鹤以独立关键姿态配合小幅关节跟随表达扑击、冲撞、砸地、连啄、翼扫与俯冲。其它动作仍使用少量原画配合关节动画；本轮不把动作样片称作整作完成。

战斗真气与突破使用的「修为灵气」分开。真气和各技能冷却随本程保存，在实际交锋与行路中恢复或推进；下一只敌人、换装、切回旧招、重试和读档都不会重置，离线也不会代为恢复。落英扇诀（原落英身法）的采集、照炉炎诀（原照炉心法）的炼丹，以及原有攻击与吐纳收益，仍在相应功法装入合法栏位时生效；仅收藏或纳入通习不提供加成。

心法换修只在山居且没有未完行程时进行：先查看旧法、新法、材料、修为灵气（归真后为功德）和调息时长，再亲点确认。首次确定心法免费且立即生效；以后卸下重装也不会再获得免费机会。付费调息期间旧心法继续生效，完成后才转入新法，期间不能出发或再次换修。

交锋中可翻阅衣冠、功法并播放独立人物特写；实际换装、通习、装配／研习功法及强化身上装备暂时锁定，交锋结束后可手动操作，心法换修另须满足归山条件。浏览不会在战后自动替你应用选择。

## 桌面相伴

默认尝试 1200×320 的透明天空小窗。场景入口融入人物、石台、药圃、丹炉和小狐；需要时才展开宣纸册页。

- I：行装；A：丹方；R：修行札记；G：采药；M：小印设置
- 空格：暂停/继续；F2：普通窗口/桌面小窗；Esc / F8：安全恢复普通窗口
- 拖动顶部空白安全区移动。右上「山」字小印提供保存、音量、节能、宽度、恢复与退出
- 位置、宽度、窗口模式、音量与暂停状态会记住；恢复时会把窗口放回可见区域
- 鼠标穿透默认关闭；macOS/Linux X11 可尝试局部空白区穿透，场景入口和恢复区始终保留输入。Windows/Wayland 不启用穿透

打开行装、丹方或札记时，左侧浮现独立人物特写，右侧纸页展开并显字；山中场景与实际人物不移动、不缩放。行装特写站立以展示裤装和鞋履，修行札特写可盘坐吐纳。功法页的「展卷试演」只影响特写，不消耗修行资源，也不改变场景活动或启动切磋。暂停停止修行、游历和增益计时，界面过渡仍可操作。详见 [第一卷设计与验证](docs/CAMPAIGN_DESIGN.md) 和 [v1.3.1 动作修订记录](docs/COMBAT-v1.3.1-QA.md)。

快捷键只在游戏窗口有焦点时生效。透明、置顶和窗口位置受系统合成器影响，详见 [桌面说明](docs/DESKTOP.md)。

## 保存与离线

未暂停时约每十秒自动保存，换装、暂停和关键操作即时保存，退出前再次保存。位置和音量等设置会随下一次保存写入；暂停期间改了设置，可点「保存」或「保存离山」。存档为 Godot `user://` 目录中的 `cultivation_save.json`，另留 `.bak` 备份。新版兼容原有山居档与装备，存档格式仍为 v4，以新增字段保存功法栏位、通习、付费研习／调息计时、本程战斗真气与逐技能冷却。旧功法重数保留，原选择迁入对应栏位；通习容量不足的书卷暂时收起，不会丢失等级。已通穴位以 ID 保存；旧档穴位计数只迁移为原有六穴，不赠送分支。v3 的十六段境界原位保留。已开放的旧三条山路不会被新章节条件重新锁住，旧通关可补领首通心意。旧连续切磋开关清除为手动出发；中途离山的历练读档后停在下一只未击退怪物，等你再点继续。

离线最多结算八小时，与相同设置的在线修行采用同一套时间逻辑。已支付的功法研习与心法调息可在此范围内继续，灵狐游历也会继续，回山赠礼自动收入；离线不会进行历练、恢复战斗真气、推进技能冷却或自动开启木箱。暂停后离山不会积累离线收益。时钟倒退不给额外收益，坏档会尝试备份恢复并保留损坏文件。

背包最多 100 件，穿戴物品也计入；满包的新装备奖励转成资源，旧物不会被挤掉。分解前需确认，穿戴中的物品受保护。重置会清空进度和装备，需单独确认。

程序只读写自己的存档与窗口，不读取其他应用、浏览器或桌面文件。
