## 换装比较

衣冠选中物品 → “换装比较 ↗”。属性页显示攻击、防御、闪避（百分点）和吐纳修为；翻页查看兵器形制、自带招、武式与主动栏条件。强化已计入，空槽、同件与满行箧均可比较。只在亲自点击“穿上此物”时换装，交锋中只可翻阅；旧物保留，不消耗材料或重置真气/冷却。

## 交锋札

在衣装页点击属性区“点开详解”，查看三部分：

- **主要属性来源**：攻、防、气血、速度、闪避、真气及节耗/调息，显示当前实际有效值与主要组成；不是所有战斗修正的完整百科。闪避显示准备状态参数，实际判定仍受动作阶段等影响。
- **战术**：均衡沿用原轮转；强攻偏向进攻，低血保留治疗优先；守势优先合格治疗和护盾；节气按真气预留择招，必要时普攻。只调整合法技能顺序，不赠送伤害、冷却或资源。可能更快也可能多受伤，不保证某一种战术安全或最优。战中锁定，选择用于下一场。
- **最近五场战报**：胜、败、归山均可记录。伤害只计实际气血差，治疗计真实回复，护盾生成与实际吸收分列；落空不冒充闪避。技能次数和耗气按已提交起手计，包含被打断，不随多段接触重复计算。战报不发奖励。
