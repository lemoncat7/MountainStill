# 主动栏满位替换

本增量在既有功法页中补齐「想换一招」的操作。主动栏已满时，不再要求先翻到旧功法、卸下，再返回新功法；点击「替换主动…」后，页面明确显示将装入的功法，并由玩家选择要替下的旧功法。

- 支持原有一格和两格主动栏。新功法留在被替换的原位置，另一主动、武式、心法和辅修不变。
- 仍使用已有初悟、通习、境界与栏位资格；不增加容量、消耗、属性或奖励，不自动换兵器、开战或试招。
- 「暂不替换」保留原搭配并返回正在查看的功法。改看其他功法、换分类/页签、合册、开始试招或重置界面会丢弃未执行选择。
- 提交前重新验证当前主动列表与新功法资格。过时或重复选择不先卸下旧功法，不产生半套搭配或额外保存。
- 正式交锋、镜中试招、关闭、更新事务及树暂停期间不能提交替换。容量或资格变化后的刷新会清除已失效的选择。
- 选择过程仅保留在内存；保存仍为 schema 4，Bootstrap ABI 1。已装配技能各自的战斗冷却与真气逻辑不变。
