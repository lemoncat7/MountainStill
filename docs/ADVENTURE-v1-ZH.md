# 山隐 · 山路与经脉 Adventure-v1

版本：1.2.0。此次交付是基于现有山居单机内容的可玩切片，目标是走通「手动选关 → 关内战斗 → 概率掉落 → 换装/通脉 → 继续修行」循环，不代表商业完整版、美术全量升级或目标平台认证完成。

## 从哪里开始

1. 点击角色，打开「行装谱」，切到「历练」。青竹关从新档可选；听泉桥在炼气中期开放；眠云坡在筑基初期开放。
2. 选中一关后点击「整装出发」。只出发这一次；传送入关后角色侧身行走、背景向左滚动，遇敌停步自动交锋，击退两只普通精怪后经过石龛，再迎战镇关首领，胜利后传送归山。没有连续刷关开关。
3. 途中机缘停步等待点击；归山后检查掉落木箱与行装。启封不等于穿戴，装备仍要在衣冠页手动选择并穿上。
4. 在「经脉」页选穴位，查看境界、资源与前置条件，点击「温养通脉」。也可以暂不通脉，继续原有静坐、采药、炼丹、游历与突破。

闲置、离线结算、读档都不会自行开关。中途存档离开后，已击退数与行程保存；下次需要点「继续此程」，不重复发放已经击退敌人的奖励。暂停时不会继续战斗。手动归山是终止当前一程，之后再次出发是新行程。

战斗和通脉都不是主线突破的必需条件。灵狐的独立游历功能仍可按原有设置单次或往返出游；游历不是关卡战斗。

## 概率说明

每击退一只敌人分别进行两次独立判定：

- 木箱：12%
- 直接装备：3%

两项可以同时成功，也可以都不成功。没有「每三胜必掉木箱」。三关各有三次遭遇；普通草露与灵气奖励按关卡定义发放。

普通木箱有 70% 概率产出装备，否则为资源。产出装备时，品阶条件分布为：凡品 60%、良品 28%、珍品 10%、仙品 2%。直接装备掉落采用同样的品阶分布，所以每次击退直接获得珍品为 3% × 10% = 0.30%，仙品为 3% × 2% = 0.06%。这些是直接掉落概率，不包含随后开箱的间接结果。

新档随身首箱是教学例外：保证一件凡品装备，不保证珍品或仙品。背包满时按已有规则将新装备奖励转为资源，保护原有物品。

每程第二只敌人之后、首领之前的石龛只判定一次，有 18% 概率触发一段二选一机缘。机缘保存在册页和存档内，没有倒计时；可以先合上页面，稍后再决定；角色会留在石龛等待，选择前不会进入首领战。选择成功后只发放一次结果，不能反复领取同一段机缘。

## 六穴有限成长

依次为气海、关元、神阙、膻中、百会、涌泉。各穴只能贯通一次，必定成功，只消耗页面列出的灵气、灵草、晨露；境界或前置条件不符时不可扣费。

六穴合计上限：吐纳 +13%、攻击 +4、防御 +3、采集 +12%、炼丹 +12%。这是本系统的固定有限加成，不是无限叠加成长。境界门槛依次为炼气初期、炼气初期、炼气中期、筑基初期、金丹初期、元婴初期。经脉不会反过来锁住境界突破。

## 美术与动作边界

三关分别使用竹林山径、溪流石桥、云坡山道。苔兽、溪石灵、云鹤三类常规怪物有独立造型；三位首领有独立升级轮廓和蓄势/攻击画。青竹关使用原画长幅山路，不再反射重复竹丛；其他两关暂用可拼接的反射滚动条。地面和物件是真实透明图片，未绘制不透明天空。

角色采用真实侧身原画分层、关节与按距离驱动的着地步态，头饰、上衣、裤装、鞋履、兵器保持独立。已修正小尺寸缩放的锯齿与碎边。动作仍是少量原画配合定长关节动画，不是完整逐帧动作素材库；视觉自然度需以实际运行评审，不以测试数量代替。

四门功法有不同真实时间轴与机制：剑刺/上挑/三叠连击、落英闪避后回击、聚火掌/双重炎息、护体格挡/沉掌推击。怪物有带前兆的冲撞、扫击和连续气弹。出招、接触、闪避/格挡、收势由同一战斗时钟驱动；闪避不扣血，格挡有实际减伤，敌人死亡后不再结算攻击。掌法会把已装备兵器暂收在背后，空手不会凭空画出剑。

场景人物与册页特写分开呈现，开页不移动或缩放世界。衣冠特写站立展示各部位，功法试演不消耗资源、不改变正式功法、不开始关卡。交锋期间实际换装、功法切换/研习和强化身上装备暂锁；仍可浏览与试演，战后须手动应用，不排队自动更换。

## 保存中的行程

存档记录已击退敌人、一次性石龛判定及待选机缘。重开程序后只回到庭院，需明确点击「继续此程」。继续时从下一只未击退敌人或待选石龛恢复，双方体力重新开始；已领取资源不重复。中途主动归山结束这程，再出发为新的一程。该检查点规则优先保护轻量休闲体验，不模拟离线战斗。

## 演示视频如何理解

`tests/show_scrolling_route.gd` 通过真实游戏回调录制原生 Linux 窗口，以预置普通混搭行装与人工固定随机种子展示一段完整路线。画面标注测试设置；短片中的掉落与机缘不是自然概率、自然养成时长证明。

`tests/show_technique_duels.gd` 为四列同场对照：同一高体力苔兽首领、同等基础攻防、同一随机种子，四门功法使用实际战斗引擎与角色动作；下方显示真实体力变化、闪避、格挡和接触阶段。它是受控对照，不是自然通关录像。录制时另用 1200×640 的画布配置；玩家日常小窗仍为 1200×320。

概率、无自动出发、存档迁移、重复回调防重领另有测试。视频是 Linux 原生绘制；不能据此宣称 Windows/macOS 实机通过。

## 平台、存档与交付

- Windows：x86_64，未签名；仅导出、PE 结构、资源与 ZIP 检查，未在 Windows 执行。
- macOS：Intel / Apple Silicon Universal，Godot ad-hoc，未 Developer ID 签名、未公证；仅导出、结构、权限、签名资源存在性与 ZIP 检查，未在 macOS 执行，不声称 Gatekeeper 放行。
- Linux：x86_64；本环境是 X11 / Mesa llvmpipe 软件渲染，音频为 Dummy。物理音响、硬件 GPU 与其他桌面合成器未验证。
- 本轮录制日志仍有 V-Sync 驱动限制和 shader cache 目录建立失败提示；不能称为完全无警告。历史导出运行的清理/音频警告及本轮复核详情见 `VALIDATION.md`。
- 旧档保留已有境界、物品与进度，旧自动切磋设置清除为手动出发。程序只访问自身存档，不读取其他应用资料。

聊天附件采用不超过 8 MiB（8,388,608 字节）的二进制分片。分片并非独立 ZIP，不能逐个解压；把同一平台全部分片及对应 Join 脚本放入新建空文件夹。脚本仅离线拼接、核验 SHA-256、解压，不安装、不联网、不自动启动游戏、不提升权限、不改变安全设置，遇到已有输出或符号链接会停止。不要为打开游戏关闭系统保护。

Windows 使用 `Join-Windows.cmd`，macOS 使用 `Join-macOS.sh`，Linux 使用 `Join-Linux.sh`。源码同时提供 `Join-Source.cmd` 和 `Join-Source.sh`，包含当前游戏、全部现用资源及其原始素材、说明与测试；不包含 `.godot` 缓存、构建历史或旧原型。完整说明、每组分片数量与 SHA-256 以同次交付的清单为准。

## 复现

需要官方 Godot 4.6.3 standard 与对应导出模板。先导入资源，再运行 README 所列全部回归测试。新功能的专项入口为：

```sh
godot --headless --path . --editor --import
godot --headless --path . --script tests/test_adventure_state.gd
godot --headless --path . --script tests/test_adventure_ui.gd
godot --headless --path . --script tests/test_combat_pose.gd
# 原生图形演示，使用独立测试存档与固定随机种子：
godot --path . --script tests/show_scrolling_route.gd
```

最终实测结果与已知问题追加于 `VALIDATION.md`，不把旧版日志当作新版证明。
