## 原生画面与演示

在Linux X11、OpenGL Compatibility / Mesa llvmpipe下运行实际主场景，已目视检查1200×320书页、全尾声、独立特写及六个侧身握持/防御姿态。

完整录制从新档开始，固定随机种子用于复现，通过真实按钮回调操作；无注入境界、灵气、装备、胜利或结局。Godot Movie Maker固定30fps采样，Engine.time_scale保持1。录像以正常游戏时间播放，剪辑只省略重复行路、炼丹和菜单等待，不把和平挂机数小时压成几分钟。中性浅底用于合成透明天空，非游戏新增背景。录制控制是自动化操作，并非手动鼠标录屏。

最终视频的实际时长、完整原始游戏时间和剪辑区间另见随附的演示清单。测试脚本的 --fast-proof 只用于无画面快速验证，未用于最终录像。

## 打包与平台边界

导出当前PCK资源包并从包内逐项加载121个必需资源成功；六条路线和角色地面/透明天空像素检查通过。PCK不是可双击运行的程序。

本环境未安装导出模板，因此本轮没有重建Windows、macOS或Linux独立运行包。此前v1.2.0程序不包含本轮内容。当前源码可用Godot4.6.3导入运行；导出脚本/清单已更新。Windows/macOS窗口、透明、签名和目标OS实际启动仍未验证。

音轨由游戏实际合成输出并随Movie Maker捕获；运行使用Dummy音频驱动，未验证硬件扬声器。素材是少量手绘风原画与关节/特效动画，不是逐帧手绘完整动作库。当前已知非致命Linux日志是V-Sync模式不受驱动支持；部分旧演示脚本曾出现工具提示/资源退出警告，最终验收以本版实机与测试记录为准。

## 复现命令

```sh
# 图形环境运行；目录需要可写。正常时间比例，没有快进选项。
godot --path . --audio-driver Dummy --script tests/show_complete_campaign.gd \
  --write-movie /absolute/output/campaign.avi --fixed-fps 30 -- \
  --demo --capture-prefix=/absolute/output/campaign
# 仅用于快速验证，绝不可当作实时录像：
godot --headless --path . --audio-driver Dummy \
  --script tests/show_complete_campaign.gd -- --demo --fast-proof
```

两种方式均使用隔离演示存档；不会写入玩家正式档。脚本不提供境界、物品、胜利注入；固定种子仅决定正常随机结果。
