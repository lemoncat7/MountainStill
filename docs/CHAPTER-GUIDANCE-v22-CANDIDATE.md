# 已通章节动态目标 · v22 独立候选（功能冻结）

本候选不升版本、不导出安装包、不公开发布；项目版本仍为公开 v1.3.22-test.1 基线。它不是正式版或全项验收结论。

## 修复

自然 v22 GUI 中，玩家先突破炼气中期，再首通青竹关，左侧听泉桥已可出发，右侧仍要求再次突破炼气中期。原因是历练页将作者写定的 `CHAPTERS.next_objective` 作为实时目标。

现在正文与章节 tooltip 共用只读 `_chapter_objective`：

1. 正在进行/暂停的真实历练优先；尸体未搜取、机缘待回应、败退和已过敌人数保留真实含义。
2. 脱离旧 `stage_run` 但仍待回应的机缘，与实际回应按钮保持同一优先级。
3. 当前章首通心意待领时明确告知手动领取；容量不足可稍后处理，不自动发奖。
4. 未开启章仍沿用真实章门槛。
5. 已通章复用现有 `State.chapter_status().next_objective`，按首个未通章节和真实境界确定后续目标。翻阅旧章不会退回过时的突破要求，也不会自动选章或出发。
6. 六章完成后按尚未归真、归真待写终章、终章已完成分别提示；不自动突破或写终章。
