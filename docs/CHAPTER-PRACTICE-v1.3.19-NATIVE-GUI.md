## 存档核对

`verification.json` 记录保存前后完整递归差异。保留历练与残骸档：正式 adventure 完全相等；其他差异只有保存时间和实际拖动窗口的位置。残骸搜索秒数仍0.75，奖励内容未被领取。

机缘档：pending_opportunity 的 id/run_id/stage_id 不变，kills=2、奖励、资源不变。仅正式历练 `travel_checkpoint` 从合成夹具的0变为2。这是 `cultivation_state.gd:2462` 在加载时按 kills 构造 checkpoint 的现有规范化，不是本章导航造成的新增进度；因此本报告不声称该档原始 JSON 完全不变。

新档在暂停前有自然修炼时间，不能把本轮新档描述成全资源0。试招中保存快照与最终存档相比，adventure 无变化；灵气37.3484126984124、灵草3、晨露1保持，正式 total_victories=0，combat_reports=[]。试招结果没有计入正式胜利。

## 环境限制和未覆盖项

- 音频设备不可用：PulseAudio/ALSA 初始化失败，Godot明确回落 Dummy。未验证可听音效。VSync 不支持警告是此云桌面条件；没有强制渲染或音频驱动。
- CUA 首次短暂无 runtime；按父任务要求有界等待后实际重连成功。一次 clipboard 输入超时先检查空命令/未启动，再改用逐字符输入，未重复执行未知结果。
- 外部夹具首次把 paused=true 放在 start_stage 前，合法被拒绝，seed访问run_id报错。已中止并把失败日志独立保留，仅调整项目外seed的设置顺序后重新建隔离目录。**没有产品代码修复**，该失败不计正式 GUI 运行。
- 正常窗口调整中一次 Escape 触发游戏的安全恢复，主动关闭透明。之后的奶油底不代表透明回归。全解锁新隔离档默认透明独立验证了正常窗口及条形窗口。
- `04-new-960.png` 实际仍1340×720，是早期未成功调整尺寸的观察；真正960×540见08及之后。`43-legacy-comparison-open.png` 是新档无物品的禁用入口，不作为比较页通过证据；真正比较页见52。
- 未在本轮实际单独验证试招 Esc 取消分支；已验证自然结果后“结束试招”。没有以源码/单测替代该未覆盖分支。未做 Windows/macOS 实机、系统DPI125%（这里是游戏内125%）、音频或全剧情自然通关验收。
- 所有正式窗口以实际 Alt+F4 退出；最终截图98只有桌面，未遗留本任务窗口。构建代理已收到释放通知。
