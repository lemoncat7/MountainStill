# v1.3.1 交锋、功法与行路修订

本次针对实际反馈重修动作与交锋节奏，并加入有限功法培养、独立战斗真气与技能冷却、付费心法换修。保留六章十八场交锋、十六段静修成长、独立人物特写与五部位行装。

## 查到的问题与对应修正

- 原交锋时钟在一方完整收势后才换另一方，防守者还复用了进攻者的阶段。现在双方各自推进蓄势、出手、接触和收势，可以重叠攻势；削韧累积达到阈值才打断，真正闪避或格挡后才获得相应反击。
- 原角色动作主要靠手臂，重心变化弱，兵器角度还误当作腕关节角度，造成别扭的握持。现在把刀剑朝向与有界腕角分离，肩肘腕、髋膝和重心连贯动作；手指位于柄前，施法时顺势背收。剑有刺、切、挑，扇有开合、拂扫、回势，徒手有前后手拳掌；兼容武技才改变相应普攻。移除了衣片上脱离主体的小块透明底残片，没有遮住或删去衣领。
- 独立复查发现短兵器和徒手仍沿用长剑交锋距离，造成拳掌隔空扣血。现在逻辑与绘制共用真实握点、兵刃/拳掌扫掠和每姿态身体轮廓；按敌人高度用有界肩肘调整与屈膝，不拉长手臂。接近时以小步推进，组合技保持近身位置；不够距离就真正落空，不扣气血、不削韧、不产生假命中。原生徒手 12 次伤害接触均在实际轮廓或 2.31 像素以内，9 像素的落空为零伤害。
- 原行路固定 48 像素/秒，到怪物前直接停下，脚步则仍按固定速度播放。现在景物、敌人位置与步态共用积分位移，按 108 像素/秒² 加减速。没有机缘的石龛不再让行路无意义地停一次；有机缘仍在实地点停住等待选择。
- 原怪物各姿态以整张 256×256 画布缩放，不同留白让攻击姿态缩水。现在 36 张姿态按实际头部解剖标记与着地锚点注册，不用翅膀、尾巴、特效或总画布高度定身体大小。俯身与飞行仍可改变轮廓高度。原始位图没有重绘。
- 原兵器特效是低透明度细线且在怪物后方，被身体盖住。现在使用与真实握持相同的兵器变换，前景绘制有轮廓的水彩剑痕与扇势。免费普攻仅用短兵器轨迹；耗气技能分别使用火焰、冰结、折线雷光、护罩和回春叶片，不只是同一特效换颜色。命中或格挡事件才产生接触反馈，闪避不会冒出假命中光。
- 经脉由原来六穴扩至二十二穴：任督六穴保留，新增劲锋、镇岳、游风、归藏四条四穴支脉。前置、资源、境界门槛、一次性扣费和旧档迁移都由实际状态验证。七类战斗加成进入真实战斗计算，安静修行仍可独立完成。

## 对照录制方法

原生 Godot 4.6.3 / Linux X11 / Compatibility，实际游戏大小 1200×320，30 FPS，正常游戏时间速度。透明天空录在中性底色上，未假称 Windows 或 macOS 已实机验证。

三种普攻对照是明确标注的测试配置：修士 100 气血、11 攻击、1 防御，青苔兽王 500 气血、8 攻击、1 防御，随机种子 377。真气为 0、回复为 0、主动功法和兵器技能关闭，连续记录 21 秒。它用于对照同一敌人的剑、扇、徒手动作，不代表正常首领血量或自然开局。三段实测真气始终为 0，动作仅为各自的免费普攻。

最终演示另包含正常内容的完整首领交锋，使用真实新存档、真实按钮、实际所得装备与资源。未在该段注入气血、装备、境界、胜利或伤害。完整记录还保留炼丹、手动出发、研习付款与真实训练等待；演示剪辑会明确转换场景，首领交锋段不加速、不在交锋中剪断。

最终新档原生记录长 323.125 秒，走完前两章六场交锋：普通敌人 11.67、13.77、11.43、10.50 秒，两位首领 25.20、30.10 秒。记录包含 72 次免费普攻、9 次云岚武技、5 次青锋兵器技；第二位首领为 16 次普攻、5 次武技、3 次兵器技，每次付费行动之间都穿插普攻，最低观测真气 21.88。演示保留第二位首领全部 30.10 秒交锋与前后行路，不把测试配置说成自然养成。

## 真气、功法与换修

- 战斗真气与突破用的修为灵气分开。免费普攻穿插付费主动技能；主动功法和实际兵器自带技能各按技能 ID 独立计时。蓄势提交时恰好扣费并开始冷却，被打断不退款；没真气或没冷却就继续普攻。
- 真实行路、拾取与战斗推进回气和冷却；暂停、机缘等待、离线、归山传送不推进。跨敌人、暂停保存、退出继续与换配装保留真气和技能 ID 冷却，不能换技能或重读档免费刷新。
- 十部功法使用用途标签与独立装配栏位。通习、同时研习、主动/被动运转都有境界相关数量限制；每部有自己的层数、前置、费用和训练时长。只收藏不会叠加所有被动；旧等级和原有采集/炼丹收益保留。
- 首次选择心法免费，之后在庭院先查看报价与属性差异，再确认支付修为和草露，调息完成后一次性切换。调息期间旧心法有效，禁止出发和重复换修。卸下心法也不会恢复免费资格。计时与付款随存档保存。
- 详细目录与迁移规则见 [BATTLE_QI_MANUAL_STATE.md](BATTLE_QI_MANUAL_STATE.md)，界面与特写说明见 [COMPOSABLE_MANUAL_BOOK.md](COMPOSABLE_MANUAL_BOOK.md)。

## 实际内容的节奏与成长

连续出手曾让原有低血量怪物在几秒内结束，无法看清交锋。因此本次也重调十八场实际敌人的气血、防御与伤害，不只展示高血量测试对象。

五种合法成长配装、普通掉落与零掉落两个固定种子共 180 场实战全部胜利。物理近身修订后的普通敌人约 7.8–16.8 秒，剑攻首领约 21.3–29.2 秒，其余配装首领约 26.1–40.1 秒。防御与辅助配装的慢端会超过 35 秒；这是实际伤害与步法的取舍，不是强制最低时长。每个持械首领段均穿插免费普攻以及至少两种实际付费技能。变强后重访首关，首领约 3.1–4.9 秒。

最终冻结源码的 1,920 个三场连续路段全部通过。首领中位数 29.21 秒，95 百分位 37.11 秒；19 场（0.99%）超过 40 秒，最长 46.25 秒，主要为辅助配装的云坡首领。最低获胜剩余仅 3/112 气血，已公开记录真实接近失败的随机尾部。目标是可读、可成长的交锋，并不承诺任意配装都自动获胜。安静修行路径仍为 30,772 秒（8 小时 32 分 52 秒），零战斗可完成。逐场精确数据与随机长尾见平衡报告。

## 复现录制

在 Godot 4.6.3 的图形会话中，从项目目录执行。把绝对输出路径替换为自己的可写目录，录制不会写入玩家存档。

```sh
godot --path . --audio-driver Dummy --script tests/show_earned_combat_revision.gd \
  --write-movie /absolute/output/earned.avi --fixed-fps 30 -- \
  --demo --capture-prefix=/absolute/output/earned

godot --path . --audio-driver Dummy --script tests/show_melee_contact_proof.gd \
  --write-movie /absolute/output/mist.avi --fixed-fps 30 -- \
  --demo --weapon=sword --tag=review --capture-root=/absolute/output
```

第二条为标注测试配置的零真气普攻对照脚本；`--weapon` 可选 `sword/fan/unarmed`。省略输出参数时，截图和事件记录写入 `user://revision-captures`。`--fast-proof` 只供第一条脚本做无画面功能预检，正式演示不使用该参数。
