# v1.3.42：接触起点的局部受力过渡

本版仅修复一处可复现的表现跳变：命中、格挡和破防时，头肩压缩包络在接触前为零、接触瞬间直接跳至满量。改为最多 20ms 的平滑渐入，之后完全沿用原包络。没有改变接触时刻、hitstop、伤害、随机数、移动或恢复时长；没有修改立绘、角色比例、桌面透明设置、字体、存档 schema4 或 Bootstrap ABI1。

独立代码审查确认此包络仅用于英雄和怪物局部绘制，不进入接触几何。敌人整体 scale 原本已固定为 1；本版不宣称修复未复现的整图缩放。新增起点专项在旧源码为119检查/11失败，修改后119/0。既有刚性头部、固定支撑点、网格不翻折等回归继续保留。最多20ms过渡在低帧率下可能被跨过；这是数学/运行检查，不是实际打击感或原生GUI验收。

Godot项目、Windows/macOS导出版本、更新器与打包清单统一为1.3.42；更高版本更新夹具推进到1.3.43-test.1。历史native_*工具仍是明确固定v1.3.41的历史包测试，不能用于本次v1.3.42验收，也没有把旧包摘要替换成未经核验的新摘要。

发布只使用固定main源码标签的CI新构建。Linux结构、CRC、大小/SHA、清单绑定与旧客户端载荷兼容检查不等于Windows/macOS原生安装启动。完整七件在私有草稿校验后才公开；本文件是源码封装时说明，最终发行状态与实际摘要以GitHub Release及关联Actions运行记录为准。

保留限制：Windows物理GPU黑底/透明度未证实修复；音频、DPI、多屏及长期混合负载未验收；Windows未发行商签名，macOS ad-hoc且未公证；历史两条剑式节奏断言未放宽。
