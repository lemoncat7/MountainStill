# 百工备料去向（未发布增量）

## 玩家体验

百工配方新增「缺材去向」：不必记住材料名字再翻遍山路。此页同时显示每项材料的已有/所需/缺口，提供到实际产出章节或淬炼石合成配方的只读链接。多层查看后可逐层返回原配方、原页及亲选材料。锁定山路仍显示真实境界和前置通关要求；灵髓玉明确为独立 1% 概率、无保底。材料齐备时显示「已齐备」，不显示负数缺口。

只翻页不选定出战路线、不出发、不采集、不合成、不穿戴、不消耗或发奖。亲点原有出发/制作按钮仍遵循原有检查。未完行程和已获得收获不因查看出处而改变。来源页面进入山路时清除此前未完成的放弃确认，防止沿用别处的确认状态。

合书、切换别的书、衣冠侧签、经脉快捷入口、山材/药囊，以及独立配方入口会清除备料返回上下文；只有显式备料链接保留返回链。旧控件回调校验实际 drawer 对象，不能覆盖更新的导航。

## 范围

仅修改书页呈现/导航和临时元数据。未修改已接受美术、人物场景比例、透明桌面、字体资产、战斗/奖励公式、材料目录、存档 schema 4、Bootstrap ABI 1、版本号或更新交易。没有构建或发布版本。
