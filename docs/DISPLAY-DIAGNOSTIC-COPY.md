# v1.3.30-test.1 · 手动复制显示诊断候选

设置 → 桌面相伴 → 显示诊断的三页底部均提供「复制诊断」。只有主动点击才写入剪贴板；打开、翻页、刷新、关闭和重开不会复制，也不读取已有剪贴板。复制前重新读取本地状态，输出完整三页相关字段，而非仅当前页。剪贴板不可用时明确提示，仍可查看原有页面。

报告仅包含安装宿主 / 运行内容 / 热内容版本、系统和窗口系统、当前渲染方式 / 实际驱动 / 图形 API / GPU / 厂商以及各独立透明状态。宿主仍由已有 bootstrap store 的已加载脚本常量识别；不从最新内容推断宿主，也不从平台名推断 ANGLE。实际桌面透明像素始终标明「未验证」，即使所有透明标记为真也不宣称黑底已修复。

不导出日志、存档、文件路径、用户名、启动参数或任意额外元数据；不联网、不上传、不清理 active 更新。文本字段拒绝错误类型、控制符、路径 / URL / 命令参数标记和超长输入；仅输出有限字符集、每字段最多 96 字符，固定字段报告小于 4096 UTF-8 字节。显卡名称额外允许常见 OpenGL 总线 / 指令集后缀 `/PCIe/SSE2`、`/PCI/SSE2`、`/SSE2`，但不开放任意斜杠路径。其他不兼容字符的硬件标识显示「未知」，优先避免将非预期内容带入剪贴板。分享前仍请自行查看报告。

关闭中、转场中、已替换的旧控件、禁用按钮和退出过程均不得写入剪贴板。复制不改游戏进度、暂停状态、设置、存档、Bootstrap ABI 或更新器。

专项测试：`godot --headless --path . --script tests/test_display_diagnostic_copy.gd`，配合原有 `test_display_diagnostic_pages.gd` 和 `test_display_diagnostics.gd`。专项使用替身捕获剪贴板写入，不能代替 Windows/macOS 原生剪贴板、GPU、DPI 或真实透明像素验收。本轮仍为测试候选，版本更新为 v1.3.30-test.1；全量回归、制品与原生验收另行记录，不能沿用旧版本通过结论。既有两条剑式节奏失败、超过 33.3ms 的战斗峰值及 Windows 黑底问题未宣称解决。
