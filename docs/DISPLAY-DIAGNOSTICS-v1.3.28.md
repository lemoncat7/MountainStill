## 版本不是一个数字
- **安装宿主**取现有 bootstrap store 的已加载脚本常量，不把挂载后的 ProjectSettings 或新内容脚本误认作 EXE/app 的版本；无法可靠识别时显示未知/开发场景，不猜测。
- **运行内容**可以来自内置资源或已合法激活的 PCK，可能与宿主不同。
- **热内容**是单独的热数据版本，不代表可任意无重启替换脚本。

合法旧 active 内容继续优先于新 full 内置内容。因此安装新完整包不强制显示最新玩法UI；旧内容没有本页时，也不应通过删存档/更新目录来“修复”。本页不请求下载、不激活或清空更新，不重置用户存档。宿主的后端默认值需要对应完整包；仅装 gameplay PCK 不能更换旧 EXE。
