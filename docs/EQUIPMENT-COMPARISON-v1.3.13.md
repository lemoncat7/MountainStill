# 换装比较：1.3.13 测试候选

从已发布 `v1.3.12-test.1` 的干净源码开始。衣冠选择已拥有物品后，可点“换装比较”：

- 显示当前同部位和候选的名称、现有淬炼；用正式计算方法比较整套搭配的攻击、防御、平常架势闪避和每秒吐纳。
- 闪避差异明确为“百分点”，显示72%上限、出招/接触15%折算及失衡限制；吐纳不是战斗真气。
- 后续分页显示普攻形制、真实兵器招式、武式和各主动栏条件。剑换扇不仅是攻击数值变化；武式不等于主动栏。
- 保留全部功法与物品；比较不消费、不抽奖、不模拟、不写存档、不排队换装。“穿上此物”才调用原穿戴路径，并在回调中再次检查交锋锁。
- 空槽、同一件、已移除物品与100件满行箧均有明确行为。现有强化已经包含；不额外淬炼。
- 保留美术与布局比例、旧存档schema 4及更新ABI 1。新页14px正文、12px页签，分页两项。原衣冠翻页按钮因实际最小高度撞到材料切换和穿戴按钮的问题同时修复，不靠缩字修复。

## 实现边界

`equipment_comparison()` 在独立State实例上深拷贝当前正式stats()依赖，再换装独立ledger并调用相同stats()。从不暂时换装真实State，也不调用可能补发离线收益的restore/load/save路径。每次控件重建缓存结果，draw只绘制；没有每帧克隆。

当前依赖清单完整，但以后stats()新增输入时必须同步 `_equipment_comparison_state()` 并增加非默认值测试。测试对比整份before/after字典与真实穿戴结果，不仅检查四项UI值。

这不是战力评分、胜率预测、自动配装或新的战斗系统。当前清心等增益过期触发纸页重建；预览不承诺下一场仍带同样增益。
