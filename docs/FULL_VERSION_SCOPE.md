# 山隐 Adventure-v1 · 内容范围

本次继续已确认的山居画面与宣纸册页，交付一个有开端、成长、终点和可继续收藏的离线单机作品。

## 固定内容

- 五大境界各三阶段，再到归真终章，共十六阶段、十五次突破。抵达归真即完成主线；十二段任务奖励另行按顺序领取，不作为通关门槛。起步引导简短，后期适合离线放置。
- 四门功法均可研习至五重，当前选用的一门提供吐纳、采药、炼丹或攻击效果；功法独立于兵器和衣冠，其他功法等级保留。
- 十种独立形制、四档品阶、五个穿戴部位，每件可温养至 +5。装备可自由混搭和卸下。
- 三种丹方：聚气丹与回春、澄心两种按模拟时间计时的温养增益。两种增益各持续五分钟，可各自延长至一小时；暂停时不计时。
- 灵狐伙伴、三条游历路线、六件路线见闻与亲密成长；每三次游历带回未开启宝箱，完整收集有和平获取途径。连续游历由玩家开启。
- 递进任务、引导、物华收藏和完成纪念。战斗完全自愿，不阻挡主线修行。
- 自动本地保存、备份恢复、旧档迁移、八小时离线结算、回拨时钟保护。
- 桌面小窗、透明天空、可恢复入口、记忆位置/宽度/音量、暂停与节能。

## 边界

这是有限内容单机试玩切片，不含联机、云存档、账户、内购、广告、赛季或持续运营承诺。物品的随机品阶、等级与温养提供可重玩的组合，但不将变体冒充独立美术素材。只有现有十种形制有各自对应的外观。

Windows x86_64 和 macOS Universal 从官方 Godot 模板导出，须将结构校验和目标系统实机测试区分。没有相应目标系统时不能声明 Windows/macOS 已实测。macOS 没有 Developer ID 签名及公证；Windows 没有发布者签名。

人物移动改为侧身原画部件与定长关节，掌法与持械有不同姿势；仍是有限动作库，视觉自然程度以实际录像为准。新增手动传送入关、三路滚动、不同怪物/首领、低概率掉落、持久机缘与六穴经脉，详见 ADVENTURE-v1-ZH.md。

## 完成交付条件

- 新档通过真实 UI 完成开箱、装备、采药、炼丹、任务领取、功法与游历；进阶档通过后期与终章页面。
- 数值模拟验证新档修行到终点，并比较在线小步与离线大步结算；覆盖离线封顶、时钟回退、损坏档与备份、迁移、背包满与强化边界。
- Linux 图形运行确认画面与恢复操作；输出源码和 Windows/macOS 包、中文快速入门、约一分钟真实操作演示。
- 演示若用预置进度或加速必须在画面中明确说明，不展示虚构的自然挂机进度。
- 代码冻结后重新导出、核对最终包内容和哈希，再复测图形运行。先前版本的导出或截图不替代本次最终版本验证；复验命令见 [验收记录](VALIDATION.md)。
