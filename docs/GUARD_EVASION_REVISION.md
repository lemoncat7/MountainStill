# 剑势、实物格挡与闪避属性修正

日期：2026-10-20。基于 v1.3.2 的同一份源码修正；存档格式仍为 v4。本轮仅打磨普通剑击、格挡、闪避与对应属性展示，没有增加功法或怪物目录，也没有重新导出各操作系统安装包。

## 画面修正

- 移除普通格挡前方的浅色弧形护罩。格挡由真实剑、手腕、双肘、肩部和膝部承重表达；局部火花与声音只在真实格挡接触时发出。
- 剑的平斩、直刺、回腕挑锋不再绘制宽面弧带。细短残迹采样同一把剑的真实剑尖，最长 14 像素、最宽约 1.1 像素，收势不留静态扇面；剑技也不再使用该宽面弧带。
- 近手持剑在近景层绘制一次，避免怪物头角把真实刀刃遮住。握持点、剑长、关节长度与接触判定均沿用实际角色模型。
- 闪避前后使用同一防御结果驱动髋部侧移、胸部后撤与后足踏步；至少一只脚承担体重。真实闪避显示「闪避 0」，气血和架势均不扣除。
- 「护元诀」的真实吸伤屏障保留；普通格挡不会生成它。苔兽、灵鹤的独立绘制关键姿态及原有接触反馈保留。

## 可见且真实的闪避属性

行装谱顶部显示平常闪避率、出招闪避率、失衡时的闪避率，以及基础、身法、装备、经脉四项来源。属性由当前装配实时计算；不向存档另写一个可能过期的总概率。

平常闪避率 = 基础 + 身法提高值 + 鞋履 + 经脉，最终限制在 0–72%。

- 基础为 5%；止水护体生效时为 4%。
- 身法：已学、已通习、实际装入武式或主动栏的落英，将平常基础提高到 40% + 1.8 个百分点 ×（重数−1），最高五重。它替代基础，不与基础再加一份；同时装两个栏位只算一次。仅学会或仅通习但未装配，不增加闪避。
- 落英的「身法防御」与「扇招」明确分开。剑、扇和空手都可以获得已装配身法的防御收益；落英的扇式和主动扇招仍要求持扇。功法页会显示「身法生效」和「扇招停用」的区别。
- 鞋履：素布履 +2 个百分点，踏云靴 +4 个百分点；每次淬炼额外 +0.2，最高五次。品阶、物品等级不会另行放大闪避。卸下立即移除该项。
- 经脉：太溪 +3 个百分点，风池 +4 个百分点，须真实温养后才生效。
- 出招与接触阶段只保留平常概率的 15%；失衡阶段为 0%。例如无相关装备和身法时，平常为 5%，出招时为 0.75%。

每次来招只在原有防御准备节点掷一次随机数。先判闪避，未闪避时再以同一个随机数判格挡；界面采样与动画不会再掷骰。闪避是零伤害；格挡按已有守势倍率减伤，两者不是同一种结果。

真实闪避会改变接触位置。因此判定保留「未闪身时是否够得着」的独立几何记录：本来够得着、因为闪身才离开接触区的攻击是闪避；原本就够不着的攻击只算落空，不冒记闪避，也不获得闪避反击。
