# 经脉扩充：二十二穴、四条支脉

## 玩家可见变化

原有任督六穴保留，另增「劲锋、镇岳、游风、归藏」四脉，每脉四穴，共二十二穴。气海是共同起点；四条支脉各自展开，不要求先完成任督六穴。每条支脉的起点分成左右两穴，左右均贯通后才能开启末穴。左右可任选先后，各脉可搭配，所有二十二穴最终都能修满。

- 任督：保留原六穴、价格、境界门槛和吐纳／攻防／采集／炼丹效果。
- 劲锋：削韧、出招节奏、得势反击。命中削韧影响真实的架势击破；出招速度影响前摇、接触间隔和收势。
- 镇岳：定力、格挡、收势。定力提高受压打断门槛；格挡是真实的减伤判定。
- 游风：闪避、反击、轻身。闪避的实际伤害为零；反击加成仅作用于战斗中真正赢得的反击。
- 归藏：吐纳、草露采集与炼丹。无需参与任何战斗，也可以完成全部山居境界。

各穴只付费一次，必定成功。条件逐次重新校验，重复点击或过时的按钮不能重复付费。归真后用既有功德支付灵气项，灵气仍保持零。经脉从不参与境界突破的资格判定，也不改变基础境界成本、基础山居修行速率、六章十八敌和独立掉落概率。

## 纸页

右侧原有册页内采用五个分脉页签，每次仅显示四或六穴与实际前置连线；点选穴位后右侧显示效果、境界、前置和精确费用。左侧独立人物特写与山中实际人物不移动、不缩放。交锋中可以查阅经脉，但通脉按钮锁定，战斗结束后需要再次亲手选择通脉；不会自动应用浏览选择。

## 状态与兼容

存档总版本仍为 v4，adventure 内新增 meridian_revision: 1 与 meridian_nodes（已开穴位 ID 数组）。meridian_count 继续保留作为数量摘要，不能用于解释新分支。新数组按内容中的稳定顺序输出，不依赖购买顺序。

仅含旧 meridian_count 的存档，严格迁移为原序列 qihai、guanyuan、shenque、shanzhong、baihui、yongquan 的对应前缀，原境界门槛仍校验；绝不会把旧数量分配到新支脉。新格式数组乱序可恢复，但未知 ID、重复项、非字符串、缺失前置或超境界项不会授予效果。存在新格式标记而数组缺失／损坏时，不再回退为旧数量，避免凭空授予穴位。读取不支付任何费用，保存后再次读取不重复迁移。
