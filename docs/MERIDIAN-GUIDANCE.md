# 经脉前置导航与缺口提示（v1.3.33-test.1 测试候选）

锁定穴位的「查看前置」会查阅当前尚未贯通的第一个前置穴位，支持跨支脉与逐层追溯。「返回〈穴位〉」逐层回到原来的选择。两者只翻页，不通脉、不自动采集、不扣费；通脉仍需原按钮与原有境界、前置、资源及交锋限制。手动选穴、换脉、离开经脉页或合书会清除返回路径。

前置与境界满足后，资源不足显示当前灵气（归真为功德）、灵草、晨露缺口，而不再只说「或草露不足」。灵气小数缺口向上取整显示，实际支付沿用既有精度与 EPSILON。已贯通和境界未达的说明优先级不变。

源码专项：`test_meridian_guidance.gd` 8661 检查 / 0 失败；既有 `test_meridian_ui.gd` 2717 / 0。覆盖跨脉链、逐层返回、手动导航清理、陈旧信号、陈旧通脉回调不扣费、交锋只读、功德/小数灵气/草露缺口及全部穴位在 320 / 540 高度的控件边界/互不重叠。这些是 headless 状态/几何检查，不是原生像素或平台验收。
