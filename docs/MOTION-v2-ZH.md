# 山隐 · 静坐与交互更新 v1.1.0（Motion v2）

历史版本记录，保留供追溯。当前 Adventure-v1 行为、动作与验证以 ADVENTURE-v1-ZH.md、VALIDATION.md 为准。
在完整单机篇 v1 上直接更新，使用相同的本地存档位置与数据格式。境界、装备、温养、功法、丹方、任务、灵狐游历、收藏、离线结算和暂停保存逻辑保持原有规则。旧版发布包保留，建议替换程序前自行备份存档。

## 本次更新

- 静坐有短暂安定、落座、持续吐纳、睁眼起身四段。双腿真实屈膝交叠，双手放在膝边；头部和上身轻轻呼吸，骨盆与脚保持着地。
- 静坐时逐渐闭眼。灵气光点沿细小弧线向下腹汇聚，脚边只有淡淡气纹，不铺亮光罩。
- 头饰、上衣、下装、鞋履保持独立搭配，服装随关节运动；卸下下装后仍保留不透明短裤。武器收在身旁，起身时随动作收回。
- 采药、炼丹、试招或切磋前先起身，再移动或展示动作。
- 展开/收起书页、页签切换、物品选择、穿脱反馈、木箱所得和提示条均有短而轻的过渡。
- 打开大书页时，左侧浮现独立人物特写，右侧书页展开后逐渐显字。底下的场景、世界人物、地面和物件不因界面改变位置或比例。特写读取实时装备与功法；展卷试演只在特写中播放，不改变山中活动或消耗资源。切换设置页时，特写淡出，纸页宽度连续过渡。
- 退出时先停止音频、释放场景和提示窗口，再关闭原生主窗口。
- 快速切换、关闭后立刻重开、旧按钮的重复信号不会误删最新面板。数字更新不重播翻页动画；尚未展开的控件不会接收指针点击。

## 使用

点石台或 R 打开修行札，选择“静坐”。新角色默认也会安静入座，无需常开界面。选择采药或 G 后先起身，再走向药圃。I 行装、A 丹房、M 设置；空格暂停，Esc/F8 恢复普通窗口。

## 验证与边界

本轮在 Linux 云桌面运行 Godot 4.6.3 原生 OpenGL/Compatibility 渲染。检查了完整场景、透明桌面、坐姿入出、呼吸、闭眼、27 种上衣/下装/鞋履组合、书页、装备、奖励，以及连续快速操作。自动回归覆盖原有完整单机功能、存档与新过渡状态。自动套件及可复现渲染脚本包含在源码。

演示录像由原生 Godot 渲染，使用标明的预置进度及实际界面回调。不是自然挂机时长证明。视频格式不保留透明通道，因此透明天空可能呈黑；PNG 和桌面合成截图用于分别检查透明层与最终桌面显示。

Windows 导出为 x86_64；macOS 为 Intel/Apple Silicon Universal。两者均未在相应操作系统实机执行。Windows 无发布者签名；macOS 仅 ad-hoc，未作 Developer ID 签名或公证。透明、置顶和各系统安全提示仍受操作系统支持影响。不要关闭系统安全功能。

已知限制：走路仍是正面 Q 版分层迈步，不是自然三分之四侧身步态；本次没有声称解决这一点。Linux 软件渲染环境不支持切换 V-Sync；测试使用 Dummy 音频，不代表物理音响验证。

Linux 原生导出包在本云环境正常退出（退出码 0），但日志仍可出现 Godot 窗口信号重复断开及一个 AudioStreamWAV / AudioStreamPlaybackWAV 清理警告；尚未消除，也未证明仅限 Dummy 后端。程序启动还报告不能建立着色器缓存，仍能正常渲染。PulseAudio / ALSA 在本环境无可用输出设备，会回退 Dummy，因此未做实际声音验收。
