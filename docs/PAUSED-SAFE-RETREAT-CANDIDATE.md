状态：2026-10-24。**这是已完成源码专项、独立后审和 Linux 自然档副本 GUI 的候选，不是新发布版本。** 版本字段仍为 v1.3.23；全量构建、实际发行载荷、目标系统验证和发布由后续阶段另行记录。

## 玩家行为

在正式历练中按空格暂停后，可以直接点击「归山暂歇」，不必先恢复战斗或世界模拟。归山动画完成后仍保持全局暂停；未完路线保持暂停，须明确恢复修行并亲点继续才会重返。

这解决的是暂停时返回按钮被禁用的交互摩擦，不是已证实的进度或存档丢失。原自然截图已经处于第二敌；不能把原记录的 2.6436 秒全部归因于被迫恢复运行。

独立 GUI 所有者复制第四章照炉遗墟、run 4、已过 1/3 的真实自然档，未编辑修为、装备、战斗数值或路线进度；原自然档链 12 份主备 SHA 前后不变。

- **960×540、125% 字号**：实际第二敌战后、遗物待搜取时按空格暂停；直接归山仍暂停，1/3 与 pending_corpse 完整保留。
- **1200×400 条形、125% 字号**：真实第二敌 fight 中按空格暂停，直接归山成功；三连点击仅新增一条 retreat，不自动再开战，1/3 与全局暂停保留。
- 两个 profile 均正常退出并重开，四次进程均 exit 0；重载仍在家、仍暂停、不自动开战。两个 profile 的 closed-save→reloaded-save 差异都只有 saved_at。
- 暂停→到家：普通遗物分支仅 journal_entries/saved_at；真实 fight 分支另有一条预期 retreat combat_report。初始档→暂停之间存在合法离线/在线收益、设置及战斗，不能扩大为整个会话仅 saved_at 变化。
- 最终主备档均可解析且语义核对；本 GUI 是正常主档重载，**未人为破坏主档来测备档 fallback**。
