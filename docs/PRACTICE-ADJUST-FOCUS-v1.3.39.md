## 范围

完成镜中试招后，搭配对照的「回山调整」会先结束试招，再重建衣冠页。旧焦点目标属于已移除的试招控件，原回退列表没有衣冠控件，键盘操作因此中断。

本轮仅为此转场选择安全的当前衣冠部位，并将待处理焦点保持到实际控件可操作时。中途重建使用新控件实例；新的焦点选择优先，关闭或销毁目标不能复活旧焦点。焦点不会落在穿戴、卸下、开箱或付费按钮上。未持有焦点的调用不会抢焦点。不改山居原有 Tab 开合行装快捷键，衣冠继续用方向键导航。

同一实际 Viewport 专项在旧源码 51 检查 / 6 失败，在候选 51 / 0。覆盖自然 Tab 抵达回山调整、Enter 按下/重复/释放、胸部与兵器部位、960×320 和 1200×400 布局重建、后续 Enter 只检视、方向键、无焦点调用、新焦点优先及关闭清理。正式状态、装备、资源、RNG 和已完成试招报告均检查不变。
