## 隔离方式与证据边界

`run.py` 为三次进程分别创建独立 XDG data/config/cache。普通实测入口是候选的 `res://main.tscn`，非 bootstrap；不访问真实存档、不运行自动更新。窗口启动、按钮、鼠标悬浮、Esc、F2、I、Alt+F4 均通过真实桌面操作，截图来自实际显示输出；不是 headless 渲染冒充 GUI。

1. **new**：调用真实 `new_game()`，默认新档属性、主动功法 mist；仅将自动推进关闭、暂停开启、arrival_seen 设为 true、窗口 960×540 和游戏 UI 1.25。故它是隔离新档状态验证，**不是首启引导验收**。
2. **control**：使用既有诊断产物 `build-identity-diagnosis-v19/coverage.json` 的 commons 第六章 idle save；其 realm=12、已学 frost/thunder。先用实际 state API 合法 attune/equip 为 frost+thunder，不注入结果计数；进入试招前确认没有 stage_run。这证明给定合法状态下的 GUI 行为，**不证明本轮从新档自然培养至第六章**。
3. **legacy**：`legacy-preview.gd` 是副本之外的 GUI 专用夹具。它用真实试招 session 推进至结束，然后在 report 适配层移除 `control_metrics_version`、`slowed_enemy_starts`、`enemy_action_interrupts`，保持候选脚本不变。随后实际查看界面、悬浮说明、点击结束、关闭窗口。**不是自然旧档迁移，也不是这一局真实时间战斗证据**。

三次启动前后的完整 JSON 存档都保留，设置、脚本与原始日志可复查。

## 布局、透明与根代理复核

- **960×540 @ 游戏 UI 125%**：右侧计数没有碰左侧气血/真气；结束、再试、说明按钮均在可见范围内。缺字段短句亦清晰。
- **1200×400 @ 游戏 UI 125%**：结果列与底部按钮完整；说明浮层完全处于客户区内，底部操作仍可见。浮层覆盖其后的正文属于正常暂时叠层，移开后正文恢复，没有残留遮挡。
- 原生透明天空透出桌面，地景仍不透明；切换条形模式未观察到角色/场景拉扯比例回退。本次是定性视觉核验，不是像素级跨版本图像差分。
- 根代理于 11:14 UTC 左右实际查看 `19-control-first-result.png`、`26-control-strip-retry-result.png`、`27-control-strip-help.png`，复核意见：两窗口统计列无碰撞/裁切；说明含收势、非避免命中、可重叠且完整，底部按钮可见。
- 图 10 名为 `new-strip-transition`，但该时刻仍处于试招结果会话，F2 被保护逻辑忽略；**它不是 1200×400 证据**。实际条形模式证据从图 23 开始。
- 图 25 是一次点到非按钮文字后的未变化画面；随后以实际按钮重新点击成功，不作为产品故障。

三次均实际 Alt+F4 关闭，`new/native.log`、`control/native.log`、`legacy/native.log` 均为 **NATIVE_EXIT=0**；图 14、31、36 为退出后桌面。没有 SCRIPT ERROR。

历练数据、正式 reports 完全不变；胜数分别 0→0、15→15、0→0；三个新增控场字段均未写入存档。详见 `verification.json`。这证明所测会话未污染正式进度/报告；不是所有未知存档的全称证明。
