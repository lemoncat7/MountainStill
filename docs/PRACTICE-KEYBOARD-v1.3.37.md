## 修正内容

镜中试招存在时，原输入入口会吞掉所有非重复按键，导致已启用的纸页按钮无法用 Enter、数字键盘 Enter、Tab 或方向键操作。现在只让这些 GUI 操作键通过，仍提前返回，不触发山居快捷键。Space、Esc、F8 以及其他非 GUI 键的按下、重复、松开均在进入 GUI 前被处理；Space 暂停/继续与 Esc/F8 结束仅在首次按下执行。

没有改动战斗公式、择招、奖励、平衡、美术、字体、透明窗口、存档 schema 4 或 Bootstrap ABI 1。没有自动换装、出发或领奖。版本元数据更新为 1.3.37 / 1.3.37-test.1，更新回归夹具的后续版本同步为 1.3.37-test.2；没有修改更新交易逻辑或权限。
