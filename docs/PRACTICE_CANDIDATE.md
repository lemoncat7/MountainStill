# 敌情与镜中试招（候选，未发布）

基于冻结恢复版 `1.3.11-test.1` 的单一体验增量，不改版本号或正式存档结构。

## 用户路径
行装 → 衣冠属性入口 → 交锋札 → 敌情。开放路线逐敌查看规范属性与真实模块起手/机制；未开放路线只显示锁定说明。

在山居且无未完成历练/心法调息时，以当前合法拥有搭配试招。普通敌距离 88、Boss 距离 120，与正式历练一致。试招合上册页，完整呈现原角色与场景；左上暂停/结束，Space 暂停、Esc 结束。结束自动打开临时报告。仅同敌、同固定种子比较上次完成试招的耗时和承伤；明确胜败，不把一次试招当作胜率。取消不覆盖前次完成记录。

## 隔离边界
- 复用 DuelTimeline，深复制当前有效属性/装备/功法快照；独立 RNG，固定种子 17。
- 试招副本从满气血、满真气、零冷却开始，正式资源及冷却不变。
- 正式 `_process` 世界更新在试招期间早退；不发放奖励、不推进任务/历练/研习/游历、不写正式战报。
- 保存/正式资源持久化/正式战报入口有守卫；退出程序先恢复真实世界再按原流程保存。
- 不修改 State 存档格式，报告比较仅驻内存（最多开放敌人数），重启不保留。
- 120 秒模拟上限；可暂停、取消、完成后重复进入。命中音效、飘字、护盾与受击反馈共用无结算的呈现方法。
- 透明窗口收册延迟回调不能在试招中重新开启穿透；重建导航后仍禁止修改正式世界。
- 未改变任何美术资产、场景比例、字号布局或战斗模块数值。
