# 山隐 Adventure-v1 · 入山手册

## 这一版可以玩到哪里

从炼气初期到归真，共十六个阶段。主线抵达归真后不会清空山居，仍可以继续静坐积累道行、研习四门功法、温养衣冠、让小狐出游、补全收藏。没有转生重置要求，没有每日签到或错过就消失的奖励。

## 第一次打开

桌面下沿的山居是可操作的小窗，不是壁纸。支持透明的桌面会露出背后的天空区域；系统不支持时保留正常背景。新档默认随缘修行。第一次建议点石台看「入山小记」，任务的说明就是逐步引导。

人物初始没有装备，始终有白色短裤。点人物 → 衣冠 → 启封随身木箱，点物品，选择「穿上此物」。开箱不会替你自动穿戴。

## 修行与突破

点击石台进入修行札记：

- 静坐：以当前吐纳速率积累灵气
- 采药：基础每八秒一株灵草、每二十四秒一滴晨露
- 炼丹：使用当前选择的丹方，成丹时才扣材料；炉中耗材不足后以当前吐纳速率的三成静坐，不会扣成负数
- 随缘：自动静坐、采集突破材料，在尚未归真且灵气不足时服用已有聚气丹并突破。不会自动炼丹或服用两种增益丹。手动选择具体活动后会停用随缘

突破需要灵气与灵草，齐备即可成功，没有失败率。基础无辅助自动流程约八小时三十三分，实际时间随功法、衣冠、赠礼和丹药改变。新手阶段先短后长，适合放在桌面慢慢看。

## 功法怎么选

四门功法均独立于兵器和衣冠，当前选择的一门生效：

- 云岚剑诀：初始已学一重；每重增加三点攻击，战斗依次使出直刺、挑势与三叠
- 落英身法：炼气中期可研习；每重提升采集速度百分之十二，战斗侧闪后反击
- 照炉心法：筑基中期可研习；每重提升炼丹速度百分之十五，不增加材料消耗，战斗使用火掌与双炎息
- 止水内功：筑基初期可研习；每重提升吐纳百分之八，战斗护体格挡后推掌

达到相应境界后解锁，消耗灵草与灵露（晨露）可研习到五重。切换不会清空其他功法等级。点「展卷试演」可在书页左侧观看当前功法，纸页保持打开；不耗材料，也不启动战斗。特写独立于场景人物，开合书页不会移动或缩放世界。战斗中实际切换、研习功法与穿脱装备暂时锁定，结束后手动操作。

## 丹方

在丹炉的丹房中选丹方，再开炉。材料不足时按钮会改为「循香采药」。不同丹方分别保留未完成的炼制进度，切换回来可以接着炼。

- 聚气丹：初始可炼；基础二十秒、三草一露，服用后立即增加灵气，数量随境界增长；归真后手动服用增加道行
- 回春丹：炼气中期解锁；基础三十秒、五草二露，采集速度增加百分之五十，持续五分钟
- 澄心丹：筑基初期解锁；基础四十五秒、八草三露，吐纳增加百分之三十五，持续五分钟

回春和澄心需要手动服用。相同增益可延长，最多积存一小时。所有增益按实际结算的模拟时间消耗，暂停时停住。

## 衣冠、温养和木箱

头饰、上衣、下装、鞋履、兵器五部位分别穿脱。剑与扇共用兵器栏，换上衣不会换掉裤子或功法。物品有十种形制、四档品阶，等级和属性随所得阶段变化；不是上百种独立美术。

每件可温养至 +5，衣冠页使用「淬炼」按钮，所需草露会列在物品详情中，必定成功。温养保留原物品身份和外观，不会悄悄变成另一件装备。未穿戴物品可在确认后分解成灵草。

首箱保证一件凡品（普通档）一级装备；后续木箱有七成机会出装，其他情况给资源。四档在衣冠页显示为凡品、灵品、珍品、仙品。背包最多一百件，穿戴物品也计入；满包不会删除旧物，新增装备机会转换为资源。灵狐每三次游历带回一只木箱；历练击退的木箱 12%、装备 3% 是独立低概率判定，可以同时获得或都没有，没有每三胜保证。直接装备的珍品、仙品概率分别为每次击退 0.30%、0.06%。

## 手动入关与经脉

行装谱「历练」选关后点「整装出发」。传送阵入关，角色侧身步行、山路向左滚动；遇怪停步自动交锋，继续行进，首领胜利后传送归山。每路两只常规敌人加一只首领，三路场景与敌人不同。闲置、离线和重载不自动出发。

首领前有 18% 机会遇到石龛，点击后选择收取草露或参悟灵气；没有倒计时，未选择时一直等候，退出重载也保留。途中退出会从下一只未击退敌人重新开始，生命重置，不重复已经获得的奖励。

「经脉」页按顺序开六穴，详情显示所需境界、灵气、灵草和晨露；开通永久增加有限属性，不开穴也可以正常突破主线。

## 与狐同行

点山中的小狐或行装谱「寻缘」页：

- 青竹小径：五分钟
- 听泉溪谷：十分钟，筑基初期解锁
- 眠云山巅：二十分钟，元婴初期解锁

出发不消耗装备、没有失败惩罚，完成后资源、亲密和纪念物自动收入。三条路线各有不同见闻；其中共有六件可收藏的小物。小狐归来后会停下，只有主动打开连续游历才会重复。战斗与游历分别控制，全部主线与收集都可以不战斗。

## 山居小记与终章

十二段任务循序展开，达到条件后自己领取。已经提前完成的行为会计入，不要求重复。任务没有失效日期，物华录会保留已经发现的形制，即使后来分解了那件装备也不会遗忘。

抵达归真即触发终章并记录完成时刻，不要求先做完任务或收集。最后一段任务另有一次性赠礼，须按任务顺序手动领取。之后的修行是自由收藏与养成，没有强制新周目。

## 离线、暂停与恢复

关闭后最多计算八小时。离线和在线使用相同模拟规则；小狐可继续游历，但不会偷偷开箱或替你战斗。暂停后保存离山则不计算离线收获。切换电脑需要自行备份存档，本版没有云同步。

按 Esc 或 F8 可恢复普通窗口，关闭透明、置顶和穿透。快捷键只在游戏有焦点时生效。失去焦点时先点右上角「山」字小印，或用系统应用切换器选中游戏。

设置可以调整音量、宽度、节能和窗口模式；拖动顶部空白区改变位置。位置会在下次保存时记住，换屏后会尽量回到可见区域。未暂停时约每十秒自动保存；暂停期间改了音量或移动窗口，可点「保存」，或用「保存离山」退出。

暂停冻结修行、游历和药力计时，不影响翻页操作；打开册页时浮现独立人物特写，场景人物不移位或缩放。

## 签名与测试边界

移动和战斗使用原创侧身部件与定长关节动画，静坐和人物特写保持原有分层造型。动作来自少量原画与关节组合，并非完整逐帧动画库。三路是有限试玩切片，青竹为长幅山径，其余两路暂用反射接缝底图。

目标导出为 Windows x86_64、macOS Universal 和 Linux x86_64；具体包的检查记录见 [验收记录](VALIDATION.md)。本次执行环境是 Linux，不能替代 Windows/macOS 实机启动和透明窗口测试。Windows 无发布者签名；macOS 只有 ad-hoc 签名，无 Developer ID 与公证。不要关闭系统整体安全保护来运行。

视频是运行中的真实游戏操作；预置或加速进度会在画面明确标注。录制视频可能把透明天空转成黑色，实际桌面透明效果以桌面截图为准。
