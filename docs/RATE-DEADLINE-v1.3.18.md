# v1.3.18-test.1：限流提示按真实截止时间刷新

本轮仅修复更新服务的一处定时精度问题，不改变玩法、美术、存档格式、更新包校验或启动选择。

## 修改

GitHub 限流等待结束前，Godot 定时器偶尔提前一帧唤醒。旧服务用向上取整后的显示秒数重新安排定时器，使“等待已结束”提示可能额外滞后约一秒。新服务按单调时钟的实际剩余毫秒重排；界面仍显示向上取整秒数，剩余 1 毫秒仍拦截请求，不提前放行。

限流定时器独立于游戏暂停和游戏速度。到期仅刷新提示，不自动检查、不自动下载、不增加网络请求；取消、持久化等待及网络/下载保护不变。

## 安装边界

此逻辑属于安装包内不可热替换的 UpdateService，只在新完整安装包生效。已有 v1.3.16 / v1.3.17 的玩家无需为这一秒级提示延迟每版重装；如遇到该问题并希望修复，可下载新 Windows / macOS 完整包覆盖程序，保留用户存档目录。单独更新 gameplay PCK 不会替换旧服务。

新完整包遇到较旧 active PCK 仍按现有启动规则挂载旧 gameplay。本轮没有改变该规则，不宣称已经解决完整包内容优先选择，也没有修改旧存档或 ABI。

## 测试解释

新增测试注入剩余 7 毫秒和 1 毫秒的提前回调，直接检查重新安排的时间和保护边界；另以真实定时器测试普通、暂停及低游戏速度。原 HTTP 用例由固定睡眠 2.15 秒改为 4 秒硬上限内观察成功提示；这只是避免调度造成的测试误报，并非把更长测试等待当成产品精度改善。每轮实际提示延迟单独记录。

源码启动、真实安装包和图形界面验证结果由 BUILD_VERIFICATION 与本轮 QA 报告提供；不以单元测试替代 Windows/macOS 原生或 GUI 验证。
