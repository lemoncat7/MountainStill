# v1.3.15-test.1 石灵首领收势

以 v1.3.14-test.1 为基线，版本字符串已统一为1.3.15-test.1。发布状态以实际Release与构建回执为准；源码检查通过不等于跨平台实机验收。

- 仅石灵首领增加一张同风格屈肘收拳关键姿态：原攻击后先收拳到胸前，再落臂回待机。
- 保留所有旧 PNG；新姿态使用同一 `pose_key` 驱动绘制和像素碰撞，不使用幽灵叠图或仅渲染层插值。
- 这是一帧粗粒度收势补充，不是连续骨骼动画。攻击至收势原有主要头部横移仍存在；普通石灵和其他族未改。
- 伤害公式、时钟、RNG、存档 schema 与更新 ABI 未改。新的收势受击轮廓会改变少量实际战斗事件，不能宣称全事件字节一致。
- 已通过独立原画/原生逐帧、原生实战与几何合同检查。180场 earned 回归双方全胜，仅10场石灵首领事件变化；额外300对固定 earned 快照种子双方全胜、无新增超时或无接触伤害。火系平均剩余HP变化−0.78，个别种子HP差−17至+12，不等同于战斗无变化。
- 原生Linux试招覆盖三招、暂停精确冻结、重复退出/重入、实际受击败北与正式存档不变，10/10通过；正常生产退出重复调用无资源泄漏警告。延长试招用了QA专用生命值，不冒充自然流程。最终完整回归、性能和持续运行记录见BUILD_VERIFICATION.md。
- 现有最坏同步耗时约128ms、两项summit剑式节奏诊断仍是已知限制。Windows/macOS原生执行未在本云Linux环境验证。
