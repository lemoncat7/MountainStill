`MountainStill-Adventure-Final-Gameplay.mp4` 是当前 Linux 原生图形运行的 90.5 秒正常速度录像。使用预置普通混搭行装和样例种子 1271，画面有标注；用于稳定展示一次木箱、普通装备与机缘，不是自然掉落概率或自然养成时长的证明。

录像由真实主场景和真实按钮回调驱动：手动出发、透明传送阵、侧身步行与山路滚动、停步交锋、走近地面掉落并拾取、点击石龛选择、首领战、返程、经脉开通、实际掉落裤装穿戴、突破。开书时主场景不移位、不缩放，左侧特写独立出现。

MP4 无 alpha 通道，透明天空在录像中呈黑色；实际场景 PNG 与运行视口保留透明。上述录制运行没有脚本错误。原生发布版交互仍可出现 Godot tooltip/window 的 focus_entered、tree_exited 重复断开提示；这是保留的问题，不能称原生运行日志全净。软件驱动另有不支持 V-Sync、shader cache 路径提示。录制使用 Dummy 音频驱动，不能据此证明物理音频设备播放正常。

发布载荷审计已验证 89 项运行资源可加载、透明天空和地面 alpha、未混入旧原型资源；独立的已导出载荷保存/重载检查确认经脉开通保存和历练手动暂停。源码 ZIP 在全新目录导入，并通过三路、中断恢复、状态、界面、换装锁、传送和场景不重构的回归检查。

## 数值与可复现性

击退奖励由 `cultivation_content.gd` 中配置控制：木箱 12%、直接装备 3%，两个独立判定允许同时发生；装备品阶为 60/28/10/2，因此单次击退直接珍品 0.30%、仙品 0.06%。无每三胜保证。机缘在首领前一次判定，概率 18%。灵狐寻缘是独立系统，其旧规则不等同于历练掉落。

经脉六穴顺序开通，具有明确境界、材料成本与有界增益；未开穴不阻断主要境界成长。旧版无战斗自动修行基准约 8 小时 32 分 52 秒是状态模拟结果，不是人工连续观察；本次仍以独立养成回归保证非战斗路线可通。

## 平台与范围边界

- Linux：原生主场景完整流程已录制；发布二进制已在 X11 实际启动，手动入关并击退一敌，暂停后保存离山，退出码 0，存档记录恰为一场胜利与待续路线。重新启动后仍在庭院暂停，显示待续路线，需要手动继续；离线没有擅自交锋或重复奖励。
- Windows：官方模板 x86_64 导出，检查 PE、ZIP 与哈希；没有 Windows 主机执行验证。
- macOS：官方模板 Universal 导出，检查 Intel/ARM64 切片、权限、plist 与签名资源；没有 macOS 主机执行、Apple 签名验证或 Gatekeeper 放行验证。
- Windows 无发布者签名；macOS ad-hoc、无 Developer ID 与公证。遇到安全拦截请停止，不要关闭系统保护。
- 三路均有不同场景、常规怪和首领；青竹路是原生长幅底图，其余两路仍使用反射接缝滚动。每程为两只常规敌人加一只首领，尚无分岔地图。
- 人物为原创侧身部件加定长关节动画，敌人为少量姿势配合动作与特效，并非庞大逐帧动画库。此版本是有限试玩切片，不是商业完整版声明。

## 复现检查

先用 Godot 4.6.3 导入项目。然后运行：

```sh
set -eu
GODOT_BIN="${GODOT_BIN:-godot}"
mkdir -p builds/qa
"$GODOT_BIN" --headless --path . --editor --import > builds/qa/import.log 2>&1
for test in tests/test_*.gd; do
  log="builds/qa/$(basename "$test" .gd).log"
  "$GODOT_BIN" --headless --path . --script "$test" > "$log" 2>&1
  if grep -E 'SCRIPT ERROR:|Parse Error:|^ERROR:|FAIL:' "$log"; then exit 1; fi
done
"$GODOT_BIN" --headless --path . --script tools/audit_export_payload.gd
```

`tools/verify_builds.py` 检查平台压缩包、架构和 SHA-256；`tools/package_adventure_delivery.py` 生成不超过 8 MiB 的原始字节分片及离线拼接脚本。哈希只能检查下载完整性，不等于发布者数字签名。Windows `.cmd` 未在 Windows 执行；相同 `.sh` 流程在 Linux 的校验不能代替 macOS 运行验证。
